Decision: A red main line is pushed once for each branch and commit (to whom it goes is decided in wake/routing), and no pull request is pushed: not a red one, not a draft, not one that can merge, and not an open one that no item names, because a pull request's checks are its engineer's own to watch and the board tells that engineer when they have finished (the look at the checks), an engineer merges its own pull request once its checks pass, and the patrol finds a pull request no item names ([The pushes about checks](../../docs/design.md#watching-github), [Retiring the PM](../../docs/design.md#RETIRE_ANCHOR)), instead of pushing the red pull requests that an open item names and the old unnamed ones, or pushing the pull requests that can merge.

Rejected:
- Pushing the pull requests that can merge: rejected because an engineer merges its own once its checks pass and watches them itself.
- Pushing a red pull request or an unnamed one: rejected because the retired PM was their only recipient, and a push to the architect would add lines it has nothing to do with (wake/routing).
