Decision: A red main line is pushed once for each branch and commit (to whom it goes is decided in wake/routing), a red pull request that an open item names and that is not a draft is pushed once for each pull request and head commit to the PM, and an open pull request that no open item names, a draft included, is pushed once to the PM when it is ten minutes old, so that its engineer has time to write the changes section, and the first look at a repository records the unnamed pull requests already open as a baseline and tells nothing, because a draft's checks are its engineer's own, an engineer merges its own pull request once its checks pass, and 111 of 121 orphan pushes in the record were made within 30 milliseconds by the first look after the push was deployed ([The pushes about checks](../../docs/design.md#watching-github)), instead of pushing the pull requests that can merge or telling the first look's unnamed pull requests.

Rejected:
- Pushing the pull requests that can merge: rejected because an engineer merges its own once its checks pass and watches them itself.
- Telling the open unnamed pull requests found by the first look: rejected because they were already open before the board watched for them, so they are no news.
