Decision: The runner's beat for a turn it is running (the turn's number, how long it has run, how long since its last action and the action in one line) is held only in the daemon's memory, one for each role and item, never committed and never written to a file, replaced by the next beat and lost when the daemon stops, and the page is sent all the beats as an event when its stream opens and after every beat, because a beat is presence and not a record, a commit for it would be written every 30 seconds for each running turn, and the runner pushes it, so a board on another machine keeps it ([The live view of a turn](../../docs/design.md#the-live-view-of-a-turn)), instead of a commit for each action, the runner's report on the item renewed every few minutes, or the board asking the runner.

Decision: A turn whose last beat is more than 90 seconds old, three of the runner's 30-second beats, is shown as silent with what it last said, and not as running or as stopped, because the board cannot tell a stopped runner from a stopped turn; the 90 seconds are provisional and reopen if rows go silent while their turns run, instead of showing the last beat as current or hiding the turn.

Rejected:
- A commit for each action: rejected because every board write is a git commit and a turn makes tens of actions a minute.
- The runner's report on the item renewed every five minutes: rejected because it makes up to 12 commits an hour for each running turn, about 860 a day with the runner's three slots busy against the 1158 writes the whole board made on its measured busiest day, each waiting in the write queue, and its action is up to five minutes old, which cannot say whether the turn is moving now.
- The board asking the runner, through a port on its machine or by reading its files: rejected because a board on another machine cannot reach it, and the owner required that the board can move.
- Showing only the runner's reports: rejected because a turn runs ten minutes and more (one of an engineer took 9.5 minutes), and in that time the list would say only that a turn is running, which is what the owner could not tell from the older list either.
