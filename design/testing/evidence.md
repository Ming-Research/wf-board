Decision: Every unit check is shown to fail on the wrong input it guards, and each diagram check and each count that guards the jump limit is shown to fail on the part it protects, by an edit applied while the page is bundled that removes that part, and reports in a line that names what it waited for and what the page held, because a pass counts only if a wrong result would have failed it ([Evidence](../../docs/design.md#four-test-layers)), instead of a bare timeout or a page that did not start as the failure signal.

Decision: Every page fix keeps a witness that runs on the current page, where it must find nothing, and on a copy of the page with that fix reversed, where it must report the bug, in the lowest layer that can see the bug, in the DOM layer on the page's source edited in memory as it is bundled or in the fake DOM, and a witness whose edits no longer apply fails and is updated or retired deliberately, because a fix that nothing can see being undone could be undone unnoticed, instead of a regression test that only passes on the fixed page.

Decision: A fact that needs a layout is a test of the browser file, which keeps no witness of its own: the test is shown to fail once, when it is written, on a page with the thing it guards spoiled by a literal edit applied as the page is bundled, and the pull request that adds the test records that run, because a spoiled page for each browser test on every run would double the file's tests and seconds, past the limit of 15 tests and 90 seconds, instead of a witness for each of them.

Rejected:
- A bare timeout or a page that did not start as the failure signal: rejected because it does not say what the check was waiting for.
- A regression test that only passes on the fixed page: rejected because it would pass just as well if the fix were never made.
- A file of spoiled pages kept for the nightly run: rejected because each of its edits must follow every change to the page's stylesheet and none is run in the day, so it would go out of date unseen until the night it fails.
- A spoiled page for only the browser tests that had a witness before: rejected because nearly half of the file's tests would never have been seen to fail, and a pass counts only if a wrong result would have failed it.
